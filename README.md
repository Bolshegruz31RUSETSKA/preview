# Thumbnail AI Studio — Gemini Edition

Мобильный веб-сайт для генерации YouTube-превью по описанию и фото-референсу. Генерация изображений подключается через Gemini API (модель `gemini-nano-banana-2.1`).

## Возможности
- Адаптивный интерфейс для Android и компьютера.
- Загрузка JPG / PNG / WEBP до 12 МБ, предпросмотр и перетаскивание файла.
- Четыре стиля, поле с необязательной надписью.
- Генерация по описанию + изображению-референсу.
- Скачивание результата PNG / формата 16:9.
- API-ключ хранится на сервере, а не в браузере.

## Как получить API-ключ и запустить
Нужен Node.js 20+ и Gemini API key.

1. Получи ключ в Google AI Studio: https://aistudio.google.com/apikey
2. Распакуй архив.
3. В папке проекта создай файл `.env` на основе `.env.example`.
4. В `.env` добавь `GEMINI_API_KEY=твой_ключ`.
5. Установи зависимости командой `npm install`.
6. Запусти `npm start`.
7. Для локальной проверки открой `http://localhost:3000`.

## Чтобы сайт работал на телефоне через интернет
Приложение нужно развернуть на Node.js-хостинге (например, Render или Railway). GitHub Pages сам по себе не запускает `server.js`.
- Build command: `npm install`
- Start command: `npm start`
- Добавь переменную окружения `GEMINI_API_KEY` в настройках хостинга.
- После публикации открой выданную ссылку в Chrome на телефоне. Можно добавить сайт на главный экран через меню Chrome.

## Важно
- Не публикуй API-ключ в GitHub и не помещай его в `public/`.
- Использование Gemini API регулируется квотами и условиями Google; проверь доступность модели и стоимость/лимиты в своём аккаунте.
- При публичном запуске стоит добавить авторизацию и ограничение частоты запросов, иначе другие люди могут использовать твою квоту.
- Генеративная модель может ошибаться в тексте на изображении. Для точных надписей лучше оставлять поле текста пустым и добавлять надпись отдельно.
